Honest stubs — these tools are not bundled. Wire them when you install binaries locally. See docs/VINA.md for optional AutoDock Vina notes.

AutoDock Vina / docking

Optional. Install the Vina binary yourself and set VINA_BIN (or a future Settings path) to its absolute path. This LIMS stores compounds, SMILES, and structures only — it does not ship or require Vina to run.

OpenBabel

Not included. Use OpenBabel CLI for format conversion outside this app. PubChem / CACTUS SMILES lookup is available in Compounds / Bioinformatics.

AlphaFold / ColabFold

Not included. Fetch experimental structures via RCSB or sequences via UniProt in the Proteins module. Predicted models can be uploaded later as local PDB/CIF.

What works today

  • RCSB PDB download + 3Dmol.js viewer
  • UniProt search / fetch
  • PubChem name → SMILES (retries) + NIH CACTUS fallback
  • Local FASTA search + CIF→PDB (Biopython)
  • Chart.js analytics + CSV / ggplot2 export
  • Per-lab isolated SQLite databases

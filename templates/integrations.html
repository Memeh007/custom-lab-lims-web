Honest stubs — these tools are not bundled. Wire them when you install binaries locally.

AutoDock Vina / docking

Not included. Install Vina separately and point a future runner at receptor/ligand PDBQT files. This LIMS stores compounds and structures only.

OpenBabel

Not included. Use OpenBabel CLI for format conversion outside this app. PubChem SMILES lookup is available in Compounds / Bioinformatics.

AlphaFold / ColabFold

Not included. Fetch experimental structures via RCSB or sequences via UniProt in the Proteins module. Predicted models can be uploaded later as local PDB/CIF.

What works today

  • RCSB PDB download + 3Dmol.js viewer
  • UniProt search / fetch
  • PubChem name → SMILES
  • Local FASTA search + CIF→PDB (Biopython)
  • Chart.js analytics + CSV / ggplot2 export

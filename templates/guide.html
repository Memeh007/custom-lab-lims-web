Purpose

Custom Lab LIMS Web is a lightweight, portfolio-ready Laboratory Information Management System for any lab type. It runs locally with FastAPI + Jinja2 + SQLite — no Streamlit, no cloud lock-in.

Use it to track samples, compounds, assays, protocols, proteins, and audit events with role-based access.

First-run setup

  1. Start the app and open http://127.0.0.1:8000.
  2. Complete /setup: lab name, code, type, colors, timezone, admin account, module toggles.
  3. Sign in. Demo seed passwords (if you ran seed.py) are documented in README — change them immediately.

Per-lab databases

Each lab gets an isolated file:

data/labs_registry.json
data/labs/<LAB_CODE>/lab.db
  • On first setup, an existing legacy data/lab_lims.db is migrated into data/labs/<CODE>/.
  • Settings → Per-lab databases: create empty labs or switch active lab.
  • Switching clears your session so users/credentials cannot leak across labs.

Compounds & SMILES

In Compounds, use Fetch SMILES with a common name (e.g. aspirin). Lookup order:

  1. PubChem PUG REST (retries on transient errors)
  2. NIH CACTUS Chemical Identifier Resolver fallback

Hits autofill name, SMILES, and molecular weight when available. Bioinformatics has the same lookup helper.

Modules

  • Samples / Compounds / Experiments — inventory and assay records
  • Husbandry — organism/colony/culture events (label is configurable)
  • Protocols — Markdown-friendly text
  • Proteins — RCSB download, UniProt, 3Dmol viewer
  • Bioinformatics — local FASTA search, CIF→PDB, SMILES
  • Analytics — Chart.js + CSV + ggplot2 script export
  • Integrations — honest stubs (Vina optional — see docs)
  • Users / Audit — roles and activity log

Toggle visibility under Settings → Modules.

Security (local tool)

  • Default bind is 127.0.0.1 — not meant for the public internet.
  • Session secret lives in data/.session_secret (gitignored).
  • Databases and uploads are gitignored; never commit real lab data.
  • Upload paths are sanitized against directory traversal.
  • See SECURITY.md for hardening notes and optional HTTPS.

Backups

Copy the active lab folder (and registry) while the app is stopped, or use SQLite .backup:

# Example
cp -a data/labs/DEMO data/backups/DEMO-$(date +%Y%m%d)
cp data/labs_registry.json data/backups/

Also back up uploads/ if you store structures there.

Run instructions

python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app:app --reload --host 127.0.0.1 --port 8000

Or use run.sh / run.bat. Full mirror: GUIDE.md in the repo root.
